# Nomad Wealth Global v7 Cloud

This is the missing major update after v6.

## Main changes

- Proper normalized Supabase PostgreSQL tables
- Cloud sync across Android, iPhone, iPad and Mac
- One-time migration from browser storage
- Shared workspaces
- Email invitations
- Viewer and Editor permissions
- Savings goals stored in PostgreSQL
- Net-worth snapshots stored in PostgreSQL
- Reminder database and email-function code
- Realtime multi-device refresh
- Existing v6 charts, monthly summary, budget progress, recurring transactions, CSV/PDF export and currency tools remain included

## Required first step

Run `supabase-schema-v7.sql` in Supabase SQL Editor.

Read `SETUP-V7.md` for simple instructions.
