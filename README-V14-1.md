# Nomad Wealth Website v14.1 fixes

This package fixes:

1. The Add Budget button now opens the connected budget form correctly.
2. Investments can be opened, edited, updated, or deleted after creation.
3. Investment cards show the previous invested amount, current value, profit/loss, and point to the graphs above.
4. The greeting changes automatically between Good morning, Good afternoon, and Good evening based on local device time.
5. The reporting-currency selector was removed from the dashboard header. Main currency remains under Settings → Profile.

No new SQL migration is required when v14 migration has already been run.
